# 项目架构（初版）

> 这是材料到货前制定的初步方案，后续会根据实际测试结果修改。

## 我想实现什么

使用 ESP32-C3 读取 LD2450 的串口数据，并在浏览器中显示目标的位置和运动轨迹。

选择 LD2450 而不是 LD2410C，是因为 LD2450 能输出目标的 X/Y 坐标，最终演示效果更直观，更适合作为简历项目。

## 当前计划

1. 先使用 Python 生成模拟目标数据。
2. 完成浏览器端雷达图。
3. 材料到货后读取 LD2450 串口数据。
4. 用真实串口数据替换模拟数据。
5. 最后增加 OLED 和目标区域判断。

## 数据流程

LD2450
→ ESP32-C3 串口解析
→ 转换为统一的目标数据
→ 通过 WebSocket 发送
→ 浏览器绘制目标位置和轨迹

## 第一版暂时不做

- 不处理雷达原始 ADC 信号
- 不开发手机 App
- 不接入云服务器
- 不做人脸或身份识别

## 还没有确定的问题

- 目标轨迹采用哪种平滑算法
- 网页资源存入 ESP32 Flash 还是独立部署
